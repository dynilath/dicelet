# Dicelet 语法规范

Dicelet 是一种骰子表达式语法，支持算式运算、骰子投掷、多结果集合以及它们之间的混合运算。

本文档定义了 dicelet 语法的完整规范，包括 BNF 范式、语义说明和示例。

## 1. 概述

Dicelet 表达式分为三个层级，从低到高依次为：

| 层级 | 名称 | 说明 | 结果类型 |
|------|------|------|----------|
| 1 | **常量表达式** (const_expr) | 纯算式，不含骰子 | 单个数值 |
| 2 | **随机表达式** (rand_expr) | 含有骰子，产生单个结果 | 单个数值 |
| 3 | **骰子集表达式** (dicelet_expr) | 含有 `#` 或 `{}`，产生多个独立结果 | 数值集合 |

高层级表达式可以包含低层级表达式作为子表达式。层级提升是单向的：一个表达式一旦包含骰子就升为 rand 级，一旦包含 `#` 或 `{}` 就升为 dicelet 级。

## 2. 词法结构

### 2.1 数字 (NUM)

数字支持三种形式：

| 形式 | 示例 | 内部表示 |
|------|------|----------|
| 整数 | `42`, `7` | `Int(42)` |
| 小数 | `3.14`, `.5` | `Decimal(3.14)` |
| 百分数 | `150%` | `Percent(1.5)` |

百分数在内部存储为小数值（`150%` → `1.5`），但在显示时保持百分数形式。

### 2.2 关键字

| 关键字 | 大小写 | 含义 |
|--------|--------|------|
| `d` / `D` | 不敏感 | 骰子投掷 |
| `b` / `B` | 不敏感 | 奖励骰（bonus） |
| `k` / `K` | 不敏感 | 保留高值 |
| `kl` / `kL` / `Kl` / `KL` | 不敏感 | 保留低值 |

### 2.3 运算符与标点

| 符号 | 含义 |
|------|------|
| `+` | 加法 |
| `-` | 减法 / 一元负号 |
| `*` | 乘法 |
| `/` | 除法 |
| `>` | 大于 |
| `>=` | 大于等于 |
| `<` | 小于 |
| `<=` | 小于等于 |
| `!=` | 不等于 |
| `(` `)` | 圆括号（改变优先级） |
| `{` `}` | 花括号（集合） |
| `,` | 逗号（分隔集合元素） |
| `#` | 重复标记 |

### 2.4 空格

空格在词法分析时被跳过，不影响解析结果。换行符 `\n` 会被预扫描视为终止符。

## 3. BNF 范式

以下是与原始项目 `slr.txt` 等价的 BNF 范式：

```
acc             →  const_expr
acc             →  rand_expr
acc             →  dicelet_expr

const_unit      →  NUM
const_unit      →  "(" const_expr ")"

const_mul       →  const_unit
const_mul       →  const_mul ("*" | "/") const_unit

const_expr      →  const_mul
const_expr      →  "-" const_mul
const_expr      →  const_expr ("+" | "-") const_mul

rand_unit       →  "d" const_unit modifier*
rand_unit       →  const_unit "d" const_unit modifier*
rand_unit       →  "(" rand_expr ")"

modifier        →  "b" const_unit
modifier        →  "k" const_unit
modifier        →  "kl" const_unit
modifier        →  ">" const_unit
modifier        →  ">=" const_unit | "<" const_unit | "<=" const_unit | "!=" const_unit

rand_mul        →  rand_unit
rand_mul        →  const_mul ("*" | "/") rand_unit
rand_mul        →  rand_mul ("*" | "/") const_unit
rand_mul        →  rand_mul ("*" | "/") rand_unit

rand_expr       →  rand_mul
rand_expr       →  "-" rand_mul
rand_expr       →  const_expr ("+" | "-") rand_mul
rand_expr       →  rand_expr ("+" | "-") const_mul
rand_expr       →  rand_expr ("+" | "-") rand_mul

dicelet_u       →  const_unit "#" const_unit
dicelet_u       →  const_unit "#" rand_unit
dicelet_u       →  "{" dicelet_ct "}"
dicelet_u       →  "(" dicelet_expr ")"

dicelet_ct      →  const_expr
dicelet_ct      →  rand_expr
dicelet_ct      →  dicelet_ct "," const_expr
dicelet_ct      →  dicelet_ct "," rand_expr

dicelet_mul     →  dicelet_u
dicelet_mul     →  const_mul ("*" | "/") dicelet_u
dicelet_mul     →  rand_mul ("*" | "/") dicelet_u
dicelet_mul     →  dicelet_mul ("*" | "/") const_unit
dicelet_mul     →  dicelet_mul ("*" | "/") rand_unit
dicelet_mul     →  dicelet_mul ("*" | "/") dicelet_u

dicelet_expr    →  dicelet_mul
dicelet_expr    →  "-" dicelet_mul
dicelet_expr    →  const_expr ("+" | "-") dicelet_mul
dicelet_expr    →  rand_expr ("+" | "-") dicelet_mul
dicelet_expr    →  dicelet_expr ("+" | "-") const_mul
dicelet_expr    →  dicelet_expr ("+" | "-") rand_mul
dicelet_expr    →  dicelet_expr ("+" | "-") dicelet_mul
```

### 运算符优先级（从高到低）

1. 圆括号 `()`、花括号 `{}`
2. 一元负号 `-`
3. 骰子修饰符 `b` / `k` / `kl` / `>` / `>=` / `<` / `<=` / `!=`
4. 乘法 `*`、除法 `/`
5. 加法 `+`、减法 `-`
6. 重复 `#`

## 4. 语义说明

### 4.1 基础骰子 `XdY`

投掷 `X` 个 `Y` 面骰子，结果为所有骰子点数之和。

```
4d6  →  [4 + 3 + 6 + 1] = 14
```

省略 `X` 时默认为 1：`d20` 等价于 `1d20`。

### 4.2 取高/取低 `k` / `kl`

- `XdYkN`：投掷 X 个骰子，保留最高的 N 个
- `XdYklN`：投掷 X 个骰子，保留最低的 N 个

被丢弃的骰子用 `*` 标记：

```
4d6k3   →  [5 + 3 + 1* + 6] = 14    （丢弃最低的 1）
2d20kl1 →  [15* + 8] = 8             （丢弃最高的 1）
```

### 4.3 算式运算

骰子表达式与常量可以自由混合在算式中，支持 `+` `-` `*` `/` 和括号：

```
1d20 + 2d6 + 4           →  [13] + [4] + 4 = 21
(10d6 + 10) * 150%       →  ([35] + 10) * 1.5 = 67.5
```

百分数 `150%` 在计算时按 `1.5` 处理。

### 4.4 重复 `N#expr`

将 `expr` 独立投掷 `N` 次，产生 `N` 个独立结果。每个结果是单独投掷的，不共享骰值。

```
6#4d6k3 → {[4+2+4+1*], [2+4+5+1*], [5+5+1*+3], [1*+2+2+3], [2+4+1*+3], [5+2*+3+3]}
         = {10, 11, 13, 7, 9, 11}
```

### 4.5 集合 `{expr, expr, ...}`

花括号内放多个表达式，每个独立投掷，产生多个结果：

```
{4d6, 3d6, 2d6, 1d6} → {[5+3+3+5], [6+4+2], [1+6], [5]} = {16, 12, 7, 5}
```

### 4.6 集合运算

当集合（`#` 或 `{}` 产生的多结果）参与算式运算时：

**规则 1：常规骰子只投掷一次，在所有独立计算中沿用相同结果**

```
d20 - {1, 2, 3, 4}
→ {[19]} - {1, 2, 3, 4}
= {18, 17, 16, 15}
```

这里 `d20` 只投掷了一次得到 19，然后在四个独立计算中分别减去 1、2、3、4。

**规则 2：`#` 产生的多个独立骰子各自独立投掷**

```
4#d20 - {1, 2, 3, 4}
→ {[17], [20], [14], [8]} - {1, 2, 3, 4}
= {16, 18, 11, 4}
```

这里 `4#d20` 产生了 4 个独立的 d20 投掷结果，与 `{1,2,3,4}` 逐项配对运算。

**规则 3：两个集合运算时，逐项配对**

如果两个集合长度相同，逐项配对运算。如果其中一个长度为 1，则该结果在所有配对中沿用。

### 4.7 奖励骰 `bN`

投掷骰子时，如果某个骰子的结果 **≥ N**，则额外投掷一个同面数骰子（递归，直到结果小于 N 或达到上限）。

触发了奖励骰的骰子用 `!` 标记：

```
2d6b5  →  [1 + 6! + 5! + 4] = 16
```

- 先投 2d6，得到 1 和 6
- 6 ≥ 5，触发奖励骰 → 投出 5
- 5 ≥ 5，触发奖励骰 → 投出 4
- 4 < 5，停止
- 结果 = 1 + 6 + 5 + 4 = 16

`!` 标记表示该骰子触发了奖励骰（即其值 ≥ N，导致额外投掷）。

### 4.8 比较计数 `>N` / `>=N` / `<N` / `<=N` / `!=N`

在骰子表达式的最后可以附加一个比较运算符 + 数值，将骰子的结果从**求和**改为**计数**：

| 比较符 | 含义 | 示例 |
|--------|------|------|
| `>N` | 计数大于 N 的骰子 | `4d6>3` |
| `>=N` | 计数大于等于 N 的骰子 | `4d6>=3` |
| `<N` | 计数小于 N 的骰子 | `4d6<3` |
| `<=N` | 计数小于等于 N 的骰子 | `4d6<=3` |
| `!=N` | 计数不等于 N 的骰子 | `4d6!=3` |

比较计数模式下：
- 详情使用 `<>` 括号（区别于求和的 `[]`）
- 不满足比较条件的骰子用 `*` 标记
- 结果值为满足条件的骰子数量

```
4d6>3  →  <3* + 4 + 2* + 6> = 2    （4d6 投出 3,4,2,6，大于 3 的有 2 个）
4d6>=3 →  <3 + 4 + 2* + 6> = 3     （大于等于 3 的有 3 个）
4d6!=3 →  <3* + 4 + 2 + 6> = 3     （不等于 3 的有 3 个）
```

### 4.9 修饰符组合（固定顺序）

骰子表达式的三个可选修饰符必须按 **固定顺序** 出现：

```
XdY [bN] [k|kl N] [>N|>=N|<N|<=N|!=N]
```

1. **`bN`** — 奖励骰（先投掷额外骰子）
2. **`k`/`kl N`** — 取高/取低（再从所有骰子中筛选）
3. **比较** — 最后对筛选后的骰子计数（替代求和）

每一步的输出作为下一步的输入：

```
2d6b5k3>3
→ ① 投 2d6，≥5 时触发奖励骰，得到全部骰子
→ ② k3：保留最大的 3 个，丢弃其余（标记 *）
→ ③ >3：从保留的骰子中，计数大于 3 的数量（不满足的标记 *）
→ 详情：<6! + 5! + 4> = 3
```

组合示例：

| 表达式 | 步骤 | 输出 |
|--------|------|------|
| `2d6b5` | 仅奖励骰 | `[1 + 6! + 5! + 4] = 16` |
| `2d6b5k3` | 奖励骰 → 取最大 3 个 | `[1* + 6! + 5! + 4] = 15` |
| `2d6b5k3>3` | 奖励骰 → 取最大 3 个 → 计数 >3 | `<6! + 5! + 4> = 3` |
| `4d6k3>3` | 取最大 3 个 → 计数 >3 | `<5 + 3* + 6> = 2` |

### 4.10 数值限制

| 限制项 | 最大值 |
|--------|--------|
| 骰子个数 (X in XdY) | 50 |
| 骰子面数 (Y in XdY) | 1000 |
| 重复次数 (N in N#expr) | 10 |
| 奖励骰总骰数（含基础骰） | 50 |

## 5. 容错解析

Dicelet 解析器采用 **strtol 式容错策略**，类似于 C 标准库的 `strtol` 函数：尽可能解析输入中的有效部分，将无法解析的剩余内容作为"尾后内容"（tail）返回。

### 5.1 两层容错机制

**第一层：预扫描（括号匹配截断）**

在词法分析之前，扫描整个输入字符串，检查 `()` 和 `{}` 的匹配情况：
- 遇到不匹配的右括号 `)` 或 `}`：截断到该位置
- 遇到 `{}` 外的逗号 `,`：截断到该位置
- 遇到换行符 `\n`：截断到该位置
- 遍历结束后仍有未闭合的左括号：截断到第一个未闭合的左括号位置

**第二层：解析器错误回退**

递归下降解析器在解析过程中，当遇到无法继续的 token 时：
- 回退到最后一个成功解析的完整表达式
- 从该位置之后的未消费内容作为 tail

### 5.2 容错示例

**输入：** `d20 + (d4+ 测试`

**处理过程：**
1. 预扫描：检测到 `(` 未闭合，截断到位置 6，有效部分 = `"d20 + "`，tail = `"(d4+ 测试"`
2. 词法分析：`d20` `+` (EOF)
3. 解析：成功解析 `d20`，遇到 `+` 后期望操作数但遇到 EOF，回退到 `d20`
4. 结果：consumed = `"d20"`，tail = `"+ (d4+ 测试"`

**输入：** `4d6 + `

**处理过程：**
1. 预扫描：括号匹配正常，有效部分 = `"4d6 + "`
2. 词法分析：`4` `d` `6` `+` (EOF)
3. 解析：成功解析 `4d6`，遇到 `+` 后期望操作数但遇到 EOF，回退到 `4d6`
4. 结果：consumed = `"4d6"`，tail = `"+ "`

### 5.3 API 行为

`roll()` 和 `parse()` 函数的返回值包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `consumed` | string | 成功解析的源码文本 |
| `tail` | string | 未解析的尾后内容 |
| `success` | boolean | 是否成功解析（仅 `parse()`） |

## 6. 示例集

### 基础骰子

| 表达式 | 输出示例 |
|--------|---------|
| `d20` | `[15] = 15` |

| `4d6k3` | `[5 + 3 + 1* + 6] = 14` |
| `2d20kl1` | `[15* + 8] = 8` |

### 算式

| 表达式 | 输出示例 |
|--------|---------|
| `1d20 + 2d6 + 4` | `[13] + [4] + 4 = 21` |
| `(10d6 + 10) * 150%` | `([35] + 10) * 1.5 = 67.5` |

| 表达式 | 输出示例 |

### 集合运算

| 表达式 | 输出示例 |
|--------|---------|
| `4#d20-{1,2,3,4}` | `{[17], [20], [14], [8]} - {1, 2, 3, 4} = {16, 18, 11, 4}` |
| `d20-{1,2,3,4}` | `{[19]} - {1, 2, 3, 4} = {18, 17, 16, 15}` |

### 比较计数

| 表达式 | 输出示例 |
|--------|---------|
| `4d6>3` | `<3* + 4 + 2* + 6> = 2` |
| `4d6>=3` | `<3 + 4 + 2* + 6> = 3` |
| `4d6<3` | `<3* + 4* + 2 + 6*> = 1` |
| `4d6<=3` | `<3 + 4* + 2 + 6*> = 2` |
| `4d6!=3` | `<3* + 4 + 2 + 6> = 3` |
| `4d6>3+2` | `<3* + 4 + 2* + 6> + 2 = 4`（先计数再加 2） |

### 奖励骰

| 表达式 | 输出示例 |
|--------|---------|
| `2d6b5` | `[1 + 6! + 5! + 4] = 16` |
| `2d6b5k3` | `[1* + 6! + 5! + 4] = 15` |
| `2d6b5k3>3` | `<6! + 5! + 4> = 3` |
| `4d6k3>3` | `<5 + 3* + 6> = 2` |

|------|----------|------|
| `d20 + (d4+ 测试` | `d20` | `+ (d4+ 测试` |

| `这行是来捣乱的` | _(空)_ | `这行是来捣乱的` |
